Zurvo

Registrado no INPI · Processo nº 512026009066-0

Aplicativo de encontros que mostra no mapa onde há movimento por perto, com chat e cutucadas em tempo real, para Android, iOS e Web.

Construído de ponta a ponta: API, banco de dados, aplicativo Flutter e aplicação web, com contrato OpenAPI único entre os clientes, autenticação segura e envio de fotos direto ao armazenamento.

  • Java 25
  • Spring Boot 4.1
  • PostgreSQL
  • WebSocket
  • Flutter
  • Svelte 5
  • OpenAPI
Detalhes técnicos
  • API em Java 25 e Spring Boot 4.1, com contrato OpenAPI único para o app Flutter e a web em Svelte.
  • Tempo real com WebSocket/STOMP autenticado; a conexão é fechada quando o token expira.
  • Login com Google (ID token validado por JWKS, RS256) e com e-mail e senha (BCrypt); JWT de curta duração; refresh token opaco guardado só como hash SHA-256; códigos de redefinição com HMAC-SHA-256 e limite de tentativas.
  • Fotos por URL assinada, com envio direto ao Cloudflare R2 e rotina que apaga arquivos órfãos.
  • Pagamento por PIX (OpenPix) com webhooks; recursos novos atrás de feature flags desligadas por padrão.
  • Privacidade: a posição exata nunca é exposta, o mapa anônimo é agregado por grade na própria consulta SQL e a exclusão de conta anonimiza os dados.
  • Moderação de fotos com ocultação automática; SDD, ADRs, mais de 260 testes; Docker Compose e staging na nuvem.

Servoi

Registrado no INPI · Processo nº 512026009069-5

Aplicativo para encontrar prestadores de serviço presenciais perto de você (diarista, eletricista, mecânico etc.) no mapa, para Android, iOS e Web.

O sistema central já cobre busca geográfica, cadastro, login, pedidos, avaliações e chat, com regras de integridade e privacidade no próprio banco de dados, testes com banco real e backup verificado por restauração.

  • Java 25
  • Spring Boot 4.1
  • PostgreSQL + PostGIS
  • Redis
  • Flutter
  • Testcontainers
  • Docker
Detalhes técnicos
  • API em Java 25 e Spring Boot 4.1; aplicativo Flutter.
  • PostGIS 3.5: busca por raio sobre coluna geography(Point, 4326) com índice GiST.
  • Regras de integridade e privacidade no próprio banco (restrições, gatilhos, papéis e visões); a API não é dona das tabelas.
  • Redis: “disponível agora” com expiração automática e limite de requisições por IP.
  • Senhas com Argon2id, JWT com refresh rotativo e revogação se um token já trocado for reutilizado, login com Google e URLs de upload assinadas (SigV4).
  • Resiliência: desligamento gracioso, tempo limite por consulta, pool limitado e degradação controlada (sem Redis a busca continua); jobs que reconciliam arquivos órfãos; backup a cada 6 horas verificado por restauração.
  • Observabilidade: Micrometer e Prometheus, com verificações de saúde de prontidão e vivacidade.
  • Privacidade: endereço oculto em atendimento à domicílio, WhatsApp nunca exposto, exclusão e anonimização de conta.
  • Testcontainers, testes de concorrência e teste de desempenho da busca; Docker Compose com contêiner da API sem privilégios.

ZapDeck

Registrado no INPI · Processo nº 512026008981-6

Aplicativo Android que transforma cartões de visita de papel em contatos digitais: o usuário fotografa o cartão e o app lê os dados sozinho, envia mensagem pelo WhatsApp, salva na agenda e compartilha por QR Code ou NFC.

Funciona sem internet e sem cadastro, com tratamento de imagem próprio e inteligência artificial opcional para casos difíceis.

  • Kotlin
  • Jetpack Compose
  • Room
  • Google ML Kit
  • Gemini (opcional)
  • NFC e QR Code
Detalhes técnicos
  • Kotlin, Jetpack Compose (Material 3), MVVM e Room, com funcionamento offline.
  • Pipeline de imagem próprio: recorte do cartão, remoção de fundo e sombras e rotação automática.
  • Leitura com Google ML Kit no aparelho; Gemini opcional (Retrofit); compartilhamento por QR Code (vCard) e NFC.
  • Chave de API fora do código, dados só no aparelho e testes com Robolectric e Roborazzi.
